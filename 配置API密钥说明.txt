================================
doudou 语音识别 API 密钥配置指南
================================

【问题】
语音识别无法工作是因为缺少 Groq API 密钥配置。

【解决方案】

方式一：修改配置文件（推荐）
--------------------------
1. 打开项目根目录下的 user_settings.json 文件
2. 在 "groq_api_key" 后面填入你的密钥：

   "groq_api_key": "gsk_你的密钥",

3. 保存文件


方式二：设置环境变量
--------------------------
在 Windows 命令行中执行：

set GROQ_API_KEY=gsk_你的密钥

然后再启动应用。


【如何获取免费 API 密钥】
--------------------------
1. 访问 Groq 官网：https://console.groq.com/keys

2. 注册账号（免费）

3. 创建新的 API Key

4. 复制密钥（格式类似：gsk_xxxxxxxxxxxxxx）

5. 粘贴到上述配置中


【Groq 免费额度】
--------------------------
✓ 每天数千次免费请求
✓ 使用 whisper-large-v3-turbo 模型
✓ 支持中文和英文识别
✓ 速度快，延迟低


【测试语音识别】
--------------------------
1. 配置好 API 密钥后
2. 启动应用：npm run dev
3. 按 F2 键开始/停止录音
4. 说话测试（确保启用了"立体声混音"）


【Windows 音频设置】
--------------------------
如果配置了密钥但仍无法识别，需要启用立体声混音：

1. 右键任务栏音量图标 → 声音设置
2. 高级声音选项 → 更多声音设置
3. 「录制」选项卡 → 右键空白处
4. 勾选「显示已禁用的设备」
5. 右键「立体声混音」→ 启用
6. 右键「立体声混音」→ 设为默认设备
