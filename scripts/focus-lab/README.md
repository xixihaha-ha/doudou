# 本地焦点实验

在项目根目录运行 `npm.cmd run focus-lab`。

实验只加载两个本地页面，阻止 HTTP/HTTPS 请求，不启动 doudou 后台。
主窗口记录 focus、blur 和 visibilitychange；小窗口展示不接收键盘焦点的按钮和滚动内容。

1. 点击主窗口输入框并输入文字。
2. 点击小窗口计数按钮并滚动，查看主窗口事件日志。
3. 再输入文字，检查输入是否仍进入主窗口。
4. 切换到其他应用作为对照，应该能看到主窗口失焦日志。
5. 关闭主窗口，结束实验。

此实验不代表第三方网页或监测系统的行为，也不保证所有系统上焦点表现一致。

## doudou 主程序

主程序已沿用 `focusable: false` 和 `showInactive()`，每次启动默认不抢焦点。
点击按钮、滚动内容，以及通过快捷键显示助手时，窗口不主动获取键盘焦点。

需要在聊天或设置中打字时，右键系统托盘的 doudou 图标，勾选“输入模式（聊天 / 设置时开启）”。
完成输入后取消勾选，再点击原来的窗口继续工作。输入模式下，doudou 会正常获得焦点。
文件选择对话框、托盘菜单和外部链接仍属于独立的系统交互，可能改变焦点。

修改后重启主程序生效。可先在记事本中输入，点击 doudou 的按钮或滚动内容后继续输入，
确认文字仍进入记事本；再测试托盘输入模式下的聊天、设置输入及退出输入模式后的表现。
